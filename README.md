# Bizus Gpt
Biblioteca original de prompts, preservada como aplicativo instalável.
## Publicação
O GitHub Pages existente publica a branch main, pasta raiz. Todos os recursos e ícones estão no repositório; nenhuma compilação é necessária. Cada alteração na main dispara a publicação.
## Instalar no celular
Abra o endereço HTTPS exibido pelo GitHub Pages.
- Android/Chrome: menu → Instalar aplicativo ou Adicionar à tela inicial; o botão Instalar app aparece quando o navegador permitir.
- iPhone/Safari: Compartilhar → Adicionar à Tela de Início → Adicionar.
Depois da primeira abertura online e conclusão do cache, a biblioteca pode ser consultada offline. Links externos precisam de internet. Com internet, reabrir o aplicativo busca a versão mais recente. Favoritos continuam locais ao navegador/dispositivo.
## Manutenção
Siga AGENTS.md para acrescentar comandos mantendo o esquema e a interface. Instruções no repositório orientam futuras sessões; a revisão recorrente é gerenciada separadamente no ChatGPT.
